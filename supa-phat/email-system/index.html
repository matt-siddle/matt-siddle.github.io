Read first, every time
Four things that went wrong, and what they changed
Gmail dark mode

The whole programme was approved before anyone saw it in dark mode. The header inverted white and the logo vanished. Go-live was held while the template was reworked, because a draft can be rebuilt by API and a live flow cannot.

One hyphen, four dead sends

Four test sends reported success and reached nobody. A hyphen in a colourway name broke an image token, and the guard meant to catch it used a pattern that skipped hyphens. The script now polls delivery instead of trusting the send job.

Every lead, one conversion

Klaviyo renders a missing profile ID as the literal word "None", so every competition entrant reached Meta with the same event ID and the whole campaign deduplicated to one conversion. IDs are now derived from the hashed email.

Draft is not pause

A flow set to draft skips anyone whose timer comes due. Manual is the pause. Learned the hard way, then written into the rules so it cannot happen twice.
